## Reportando uma vulnerabilidade

Não abra uma issue pública. Use o [relato privado de vulnerabilidades do GitHub](https://github.com/OctoCorsair/NoirForge/security/advisories/new).

Descreva o problema, os passos para reproduzir e o impacto que você enxerga. Respondemos assim que possível.

## Escopo

O NoirForge não usa rede, não executa código externo e só grava o arquivo SQLite e as exportações que você pede. Todas as consultas SQL são parametrizadas.
